# Демо на GitVerse Pages

Демо доступно по адресу `https://yourdisenchantment.gitverse.site/dobromir`.
Вместо настоящих новостей VK используются примеры из
`site/src/sample/news.example.json`. Сборка проходит с `SITE_ENV=staging`, поэтому все
страницы демо имеют `noindex, nofollow` и не предназначены для поисковой индексации.

Боевой сайт на Beget этот workflow не меняет: у него отдельные сборка и публикация.

## Включение

1. Отправить ветку `main` с `.gitverse/workflows/pages.yml` в GitVerse.
2. В репозитории открыть **Настройки -> Страницы**.
3. Включить Pages и выбрать в поле **Источник** вариант **Воркфлоу**.
4. Запустить workflow **Demo Pages** вручную или сделать push в `main`.

Без выбора источника **Воркфлоу** шаг `deploy-pages` завершится ошибкой.

## Обновление

После каждого push в `main` workflow заново собирает `site/` и публикует `site/dist`.
Его также можно запустить вручную через `workflow_dispatch`. Настоящие новости и ключи VK
для демо не нужны.

## Снятие с публикации

В **Настройки -> Страницы** выключить Pages. Это остановит публикацию демо и не затронет
боевой сайт на Beget.
