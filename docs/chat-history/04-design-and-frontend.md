# 04. Дизайн, фронтенд и стилизация

**Источник:** чаты «Добромир» (дизайн-гайд), «Новый сайт и репозиторий» (SEO, краулеры), «krov-primarhov» (анализ стилей)
**Тема:** Дизайн-система, стайлбук, SEO, доступность, компоненты

---

## Резюме

Дизайн принят 2026-10-26. Стайлбук в `site/src/pages/stylebook/`. Палитра от логотипа в `src/styles/tokens.css`. Шрифт Inter (OFL). Компоненты: Button, Section (с волной), Card, Carousel, Facts, SiteHeader, SiteFooter, Modal, PostArticle, SpecialistArticle. Лендинг из блоков (`content/page.json`). SEO: JSON-LD (Organization, Person, NewsArticle, BreadcrumbList), Open Graph, sitemap, RSS. Метрика не нужна, SEO нужен.

## Дизайн-система

- **Токены:** `src/styles/tokens.css` — единственное место цветов и размеров
- **Шрифт:** Inter (латиница и кириллица, 102 КБ, OFL) в `src/assets/fonts/`
- **Иконки:** Material Symbols (Apache 2.0, по одной в SVG, встраиваются через `lib/icons.ts`)
- **Логотип и фавиконки:** без метаданных C2PA в `public/`
- **Контраст:** основной текст 14.4:1, второстепенный 6.6:1, основной оранжевый 5.7:1, белый на кнопке 5.9:1, ссылка 7.3:1
- **Яркие цвета логотипа** помечены «не для текста»

## Компоненты

- `Button` — кнопка
- `Section` — секция с волной
- `Card` — карточка (вся карточка — ссылка), высота по содержимому
- `Carousel` — карусель (в одну строку, свежая по центру, свайп без JS)
- `Facts` — цифры с иконками
- `SiteHeader` — шапка (на телефоне — меню в `<details>`)
- `SiteFooter` — подвал
- `Modal` — всплывающее окно карточек
- `PostArticle` — новость (общие классы `styles/post.css`)
- `SpecialistArticle` — специалист
- `Breadcrumbs` — хлебные крошки

## Лендинг (блоки)

`site/content/page.json` — порядок 10 блоков:
1. hero — первый экран
2. about — о центре
3. news — новости
4. services — услуги
5. directions — направления
6. facts — цифры
7. specialists — специалисты
8. about-us — о нас
9. reviews — отзывы
10. contacts — контакты

Типы блоков: `hero`, `text`, `cards`, `facts`, `news`, `quotes`, `contacts`, `specialists`

## «Черепица» (masonry)

- `Card` — высота по содержимому, без заглушки картинки
- Утилита `.masonry` (CSS-колонки) — архив `/news/`
- Фото в новости — колонками (`post.css`)
- В карусели карточки своей высоты
- Анонс без разметки VK (`plainVkText`)

## Специалисты

- 18 человек в `content/blocks/specialists/block.json`
- Фото: WebP до 800 px, 22-55 КБ, всего 708 КБ
- Схема zod с ошибками по-русски
- Страница `/specialisty/<slug>/` и окно на лендинге
- Карточка: рамка 4:5, кадр по лицу (`Card.focus`)

## SEO

- `<html lang="ru">`, title, description, canonical
- `noindex` в staging (через layout + .htaccess)
- Яндекс и Google верификация из переменных
- Open Graph: type, title, description, url, locale, image
- Twitter Card: summary_large_image
- JSON-LD: Organization (главная), NewsArticle + BreadcrumbList (новость), Person + BreadcrumbList (специалист)
- sitemap (`@astrojs/sitemap`), RSS (`@astrojs/rss`), robots.txt
- Canonical URL, trailingSlash: "always"

## Доступность

- Ссылка «Перейти к содержанию» (skip link)
- Видимый фокус `:focus-visible`
- `prefers-reduced-motion`
- `scroll-padding-top` для липкой шапки
- Семантические теги: `nav`, `main`, `article`, `header`, `footer`
- `alt` у всех картинок, `width`/`height`
- `aria-label` у интерактивных элементов
- Модальное окно: Esc, клик мимо, «Назад», «Вперед»

## Производительность

- JS на странице: 2 КБ (0.9 КБ сжатый) при бюджете 5 КБ
- CSS: ~4 КБ сжатый
- Главная: ~185 КБ при первом открытии, HTML 15 КБ сжатым
- Фото: WebP, оптимизированные размеры
- `astro:assets` для фото специалистов (импорты, без sharp)
- Ленивая загрузка картинок

## Примеры для оформления (из ресерча)

- **Marie Curie** (Astro): крупный заголовок, акцентный цвет, волнистая граница секции, фото с большими скруглениями, кнопки-таблетки
- **National Autistic Society**: мягкая палитра, волнистый разделитель, скруглённые карточки, переключатель цветового режима
- **Антон тут рядом**: белый фон, ч/б фото, один красный акцент, фирменное начертание только в логотипе
- **GOV.UK**: дизайн-система, типографика, доступность
- **Scottish Government Design System**: шкала размеров, иерархия заголовков

## Приёмы для переноса

- Двойная рамка (border + outline со смещением) — для карточек
- Полоса цифр из 4 чисел с разделителями — для блока «Цифры»
- `<details>/<summary>` для раскрывающихся досье
- Цитата с линией слева — для отзывов
- Фото с `mask-image` градиентом — для шапки
- `text-wrap: balance`, `clamp()`, `tabular-nums`
- Видимый фокус, `prefers-reduced-motion`, `safe-area-inset`

## Чего не переносить

- Тёмная палитра (золото/бронза) — для центра нужны спокойные светлые цвета
- Внешние зависимости (Google Fonts, Метрика) — хранить у себя
- Файл 1400+ строк — разбивать на компоненты
- Код, тексты, арты без лицензии

## Нюансы

- Astro съедает пробел перед тегом, если между ними перевод строки — ставить `{" "}`
- `overrides` для `eslint-plugin-jsx-a11y` (совместимость с ESLint 10)
- `sharp` не используется для фото специалистов (импорты Astro)
- Подготовка контента: `scripts/prepare-content.ts` — первый шаг `npm run build`
- На сервере и в хуке (`CONTENT_CHECK_ONLY=1`) только проверяет, не меняет
- `content/` — ручное содержимое лендинга (блоки, специалисты)
- Исходники фото в `.gitignore`
- Фото специалистов: WebP до 800 px, без метаданных
- Типографика: пробелы, тире, «ёлочки»
- Меню из `page.json` (поле `menu`)
- Контакты шапки и подвала из блока `contacts`
- Строгая проверка полей (опечатка = ошибка сборки)
- 404 без canonical и с `noindex`
- «старше месяца» → «трех месяцев»
- `<title>` новости — до 60 знаков
- Заголовки карточек в архиве `/news/` — h3 (без h2)
- Окно специалиста: фокус внутрь, Esc, возврат фокуса
- Главная: около 185 КБ при первом открытии
