# 06. Лендинг из блоков, контент и перенос адресов

**Источник:** чат «Добромир» (2026-10-27 — 2026-10-28)
**Тема:** Лендинг из блоков, HOWTO-add-content, перенос старых адресов (P2-5), карусель, иконки, «Наверх», черепица

---

## Резюме

Лендинг собран из блоков: `page.json` задает порядок, `block.json` в каждой папке блока задает содержимое. 10 блоков: hero, center, facts, news, services, directions, specialists, about, reviews, contacts. Написана инструкция `HOWTO-add-content.md` для человека и нейросети. Составлена карта 301-редиректов со старого WordPress (27 адресов). Добавлены иконки Material Symbols (18 SVG), кнопка «Наверх», черепица для услуг и направлений. Цифры переделаны по образцу старого сайта. Новости расширены с 30 до 90 дней.

## Ключевые решения

1. **Лендинг из блоков** — `page.json` задает порядок, `block.json` задает содержимое. Блоки: hero, center, facts, news, services, directions, specialists, about, reviews, contacts.
2. **Меню строится из блоков** с полем `menu` в порядке `page.json`. Максимум 8 пунктов.
3. **Строгая проверка полей** — опечатка в имени поля = ошибка сборки с подсказкой.
4. **Контакты централизованы** — телефон берется из блока `contacts` (шапка, подвал, страницы специалистов).
5. **Новости за 90 дней** (было 30, изменено 2026-10-27).
6. **Иконки Material Symbols** — 18 SVG в `site/src/assets/icons/`, лицензия Apache 2.0. Не подключаются с серверов Google.
7. **Кнопка «Наверх»** — на всех страницах, появляется при прокрутке > 1 экрана.
8. **Черепица (masonry)** — для услуг и направлений, как архив новостей.
9. **Карусель** — центральная карточка увеличена, соседние уменьшены и бледнее, выравнивание по средней линии.
10. **Карточки новостей** — фото 16:9, текст без повтора заголовка.
11. **Первичная загрузка в воркере** — если база пустая, первый запуск сам загружает стену за срок хранения.
12. **Кнопка «На главную»** в архиве новостей.

## Технические детали

- `page.json` — список имен папок из `site/content/blocks/`
- `block.json` — содержимое блока, проверяется схемой zod
- `photos/` — фото специалистов (WebP до 800 px)
- `prepare-content.ts` — доводит фото и тексты при сборке
- `HOWTO-add-content.md` — инструкция для человека и нейросети
- `docs/content/` — документы по каждому разделу (11 файлов)
- `docs/ai-instruction.md` — единая инструкция для нейросети
- `docs/scripts.md` — описание скриптов
- `deploy/htaccess.example` — карта 301-редиректов (27 старых адресов)
- `site/src/lib/icons.ts` — встраивание иконок в разметку

## Перенос старых адресов (P2-5)

Карта 301-редиректов со старого WordPress:
- «О нас», «Контакты», «Сотрудники» -> блоки на главной
- 16 страниц специалистов -> `/specialisty/<slug>/`
- Запись «Блог» -> `/news/`
- Статьи и служебные страницы -> главная
- `feed`, `sitemap.xml`, `wp-sitemap.xml` -> RSS и карта сайта
- Все 27 старых адресов прогнаны через правила — у каждого есть цель
- Тест `redirects.test.ts` сверяет цели со специалистами и блоками

## Нюансы

- Меню: 7 пунктов (было 8, убрали «Отзывы»)
- «Центр в цифрах» и «Отзывы» без пункта меню — подсветка держится на ближайшем выше
- Карточки: центральная 106%, соседние 85%, выравнивание по средней линии
- Фото новостей: 16:9 в карусели, свои пропорции в архиве
- Иконки: Material Symbols, Apache 2.0, по одной в SVG
- «Наверх»: появляется при прокрутке > 1 экрана, без JS нет кнопки
- Услуги и направления: черепица (masonry) вместо карусели
- Заголовок новости: первая строка поста (без ссылок), ссылки вырезаются
- Текст карточки: продолжение после заголовка (без повтора)
- Обрывок ссылки в заголовке: исправлено (ссылки вырезаются из заголовка)
- 90 дней хранения: ~77 новостей, 91 фото
- 98 страниц в сборке
