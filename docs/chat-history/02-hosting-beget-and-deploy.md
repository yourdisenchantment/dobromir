# 02. Хостинг Beget: исследование, ограничения, деплой

**Источник:** чаты «Новый сайт и репозиторий», «beget-hosting-domain» (2026-10-08 — 2026-10-18)
**Тема:** Выбор хостинга, ограничения Beget, репозиторий, деплой, домен

## Резюме

Исследование хостинга Beget Blog (shared). Выяснено, что фоновые процессы (демоны) запрещены, лимит 80 CP/сутки. Python 3.10.12, Node.js 24.15.0 работают в Docker-окружении. Astro сборка проходит за 2.4 сек. Решено: cron-воркер раз в час, сборка только при изменениях, статический сайт. Домен `dobromir.ru` занят (от 350 000 ₽), выбран `добромир-крым.рф`. Репозиторий на GitVerse (приватный).

## Ключевые решения

1. **Хостинг: Beget Blog (shared)** — не VPS. Демоны запрещены (п. 6 и 22.4 правил Beget). Только cron-скрипты.
2. **Домен: `добромир-крым.рф`** — `dobromir.ru` занят (зарегистрирован 2006, выкуп от 350 000 ₽). Домен оплачен до 26.02.2027 (раньше хостинга).
3. **Репозиторий: GitVerse** (приватный), ветки `main` и `dev`. Deploy keys для сервера.
4. **Менеджер пакетов: npm** (не bun — на Beget есть Node 24, bun не документирован). uv с системным Python 3.10 на сервере.
5. **Python 3.10** — на сервере Python 3.10.12. Нельзя `datetime.UTC`, `tomllib`, `match` с новым синтаксисом.
6. **Сборка на хостинге:** Node 24.15.0 в `~/opt/node`, Astro собирается за 2.4 сек (8.8 с процессорного времени). Лимит 80 CP/сутки.
7. **Cron:** раз в час (`17 * * * *`), затем изменено на раз в 2 часа, потом на раз в час. Сборка только при изменениях. Лимит сборок `MAX_BUILDS_PER_DAY=4`.
8. **Атомарное переключение:** `public_html` — симлинк на `releases/<ts>/`. Сборка в отдельную папку, затем `os.replace`.

- Python 3.10.12, git 2.42.0, ulimit 1024
- Node.js 24.15.0 ставится в `~/opt/node`, работает из cron
- Astro сборка: 2.4 сек реального времени, ~8.8 с процессорного

- Автобэкапы файлов и баз

- `public_html` может быть симлинком

## Ограничения Beget

1. **Демоны запрещены** (п. 6 и 22.4 правил) — ни uvicorn, ни Long Poll, ни фоновые процессы
2. **80 CP/сутки** — лимит процессорного времени
3. **30 одновременных процессов** на домен
4. **Bun не документирован** — использовать npm
5. **Python 3.10** — нельзя использовать конструкции 3.11+
6. **Домен истекает 26.02.2027** — раньше хостинга (24.12.2027). Нужна идентификация через Госуслуги с 01.09.2026 для продления
7. **Персональные данные** — 152-ФЗ, серверы в РФ

## Нюансы

- `bprof.a978879k.beget.tech` — не трогать
- SSH deploy-ключ для GitVerse (только чтение)
- `.env` только в `~/dobromir-data/` (права 600)
- `SITE_ENV` без значения по умолчанию — ошибка в любую сторону вредна
- `NEWS_RETENTION_DAYS` по умолчанию 90 (было 30, изменено 2026-10-27)
- Телеметрия Astro отключена: `ASTRO_TELEMETRY_DISABLED=1`
- Домен: `добромир-крым.рф` без `www`, адреса со слэшем в конце (`trailingSlash: "always"`)
- 152-ФЗ: персональные данные на серверах в РФ
- Политика конфиденциальности нужна для публичного запуска
