## Как читать

- **Резюме** — краткое содержание сессии (2-5 предложений)
- **Ключевые решения** — что было решено и почему
- **Технические детали** — конкретные значения, команды, пути
- **Нюансы** — важные детали, которые могут пригодиться

## Правила добавления

1. Каждый новый чат — отдельный файл `NN-<тема>.md`
2. Нумерация сквозная (01, 02, ...)
3. При добавлении нового чата — обновить таблицу выше
4. Не удалять и не переписывать старые записи
5. Если чат затрагивает уже известную тему — создать новый файл и сослаться на предыдущий
