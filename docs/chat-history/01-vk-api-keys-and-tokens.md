# 01. VK API: ключи, токены и получение данных

**Источник:** чат «VK API ключ для новостей» (2026-10-05 — 2026-10-17)
**Тема:** Получение API-ключа VK, настройка доступа к группе, Long Poll, сбор постов

---

## Резюме

Разработка началась с получения доступа к VK API для сбора новостей из паблика `vk.com/dobromir.crimea`. Было выяснено, что ключ сообщества не подходит для `wall.get` (ошибка 27), нужен сервисный ключ приложения. Документация изучена через WebFetch, создана машиночитаемая схема API (569 методов). Разработан скрипт Long Poll для получения новых постов и скрипт архивной загрузки через `wall.get`. Создана тестовая группа `antarctic.test` (ID 242263522) с 16 постами разных типов для тестирования.

## Ключевые решения

1. **Сервисный ключ приложения** — единственный подходящий для `wall.get`, `wall.getById`, `photos.get`, `groups.getById`. Ключ сообщества не работает для этих методов (ошибка 27).
2. **Ключ сообщества** — нужен только для Long Poll (`groups.getLongPollServer`) и событий `wall_post_new`. Право «управление сообществом» обязательно.
3. **Long Poll** — для получения новых постов в реальном времени. Требует постоянного процесса (не cron). Ключ с правом `manage` нужен.
4. **Архивная загрузка** — через `wall.get` с `offset` и `count=100`, сервисным ключом. 3078 постов в боевой группе.
5. **Тестовая группа** `antarctic.test` (ID 242263522) — создана для тестирования, 16 постов разных типов (текст, фото, видео, ссылки, опросы, GIF, PDF, коллажи, отложенные).

## Технические детали

- **API:** `https://api.vk.ru/method/`, версия `5.199`
- **Токен передаётся** в заголовке `Authorization: Bearer <токен>`
- **Лимиты:** 5-60 запросов/сек для сервисного ключа, 10 000 вызовов/месяц без верификации бизнес-профиля
- **`wall.get`**: count до 100, offset для пагинации
- **`wall.getById`**: до 100 постов за запрос
- **`photos.get`**: до 1000 фото за запрос
- **`groups.getMembers`**: до 1000 за запрос
- **Вложения постов:** 28 типов (photo, video, audio, doc, link, poll, album и др.)
- **Фото:** максимальный размер `w` 2560x2048, ссылки временные — скачивать сразу
- **Видео:** `video.get` доступен только пользовательскому токену; через `wall.get` приходит `player` (страница плеера)
- **Long Poll коды ошибок:** 1 — продолжить с новым ts, 2 — получить новый key, 3 — получить новые key и ts
- **`groups.getLongPollServer`**: требует право `manage` у ключа сообщества

## Нюансы

- Сервисный ключ бессрочный, но при верификации бизнес-профиля (60 дней) лимиты повышаются
- Конфиденциальный тип приложения требует указать IP сервера
- Видео и товары недоступны сервисным ключом (только пользовательский токен, живёт 1 час)
- `execute` работает только с пользовательским ключом
- Ссылки на фото VK временные — скачивать при получении поста
- В группе `dobromir.crimea` 3078 постов (с 2013 года), 5968 фото, 501 видео
- 519 постов с полем `edited`, 306 репостов
- Закреплённый пост (ID 4632) отдаётся первым в выдаче, но не дублируется
