## Принято 2026-10-25 (Павел)

- **Сайт - лендинг**: одна длинная страница из блоков, внутри блоков - ряды карточек.
  Меню - переходы к блокам (`/#services`). Отдельных страниц «О нас», «Услуги» нет.
- **Конструктор**: порядок блоков - в `site/content/page.json`; у каждого блока своя
  папка `site/content/blocks/<имя>/` с `block.json` и картинками. Правка блока - правка
  его JSON. JSON лежат **в репозитории** (проверка схемой, история, откат).
- **Карточка раскрывается всплывающим окном с кнопкой закрытия** поверх лендинга; у
  раскрытой новости и специалиста есть **свой адрес** (`/news/<slug>/`,
  `/specialisty/<имя>/`): адрес в строке меняется, «Назад» тоже закрывает окно. Без JS
  карточка - обычная ссылка на эту страницу. Скрипт окна - единственный JS на сайте,
  до 5 КБ. Нужно для пересылки ссылок, поиска, sitemap и RSS.
- **Карусель - карточки в одну строку** (не сетка и не несколько рядов). Самая свежая
  новость - посередине экрана, более старые уходят за край; листать - кнопками со
  стрелками или свайпом. Ничего не крутится само; при «уменьшить движение» - без
  анимаций. Так же устроены специалисты и услуги.
- **Новости на лендинге - последние 10-12**, в конце - карточка «Все новости» на архив
  `/news/` постранично.
- **Раздел называется «Специалисты»** (не «Сотрудники»). Словаря терминов нет: его нет
  в оговоренной структуре. Часы работы, почта и прочее для подвала - из VK при наполнении.
- **Фото новостей** - уменьшенная копия от воркера, без кнопки «скачать».
- Для правки через агента - `docs/HOWTO-add-content.md` (P2-6): что куда класть, пример
  JSON для каждого типа блока, рецепты; команда проверки содержимого с ошибками по-русски.

## Типы блоков

Задаются в коде; новый тип добавляет разработчик, наполнять и переставлять - кто угодно.

| Тип | Что показывает | Раскрытие |
|---|---|---|
| `hero` | первый экран: слоган, кнопки «Записаться» (звонок) и к блоку «О нас» | - |
| `text` | заголовок, абзацы, картинка | - |
| `facts` | цифры с подписями (и источником, если есть) | - |
| `cards` | карусель карточек в строку: картинка, заголовок, подзаголовок, кратко | окно поверх страницы |
| `specialists` | карусель специалистов: фото (рамка 4:5 по лицу), имя, должность, «кратко»; поля в `block.json`: `slug`, `name`, `position`, `short` (необязательно), `photo` (файл в `photos/`), `description` (список абзацев; строка «— ...» - пункт списка) | окно поверх страницы; страница `/specialisty/<slug>/` |
| `news` | карусель последних новостей из VK, свежая - посередине; настройки: заголовок, сколько карточек | окно поверх страницы, свой адрес |
| `contacts` | адрес, телефоны, как добраться, ссылка на карту и группу VK | - |

## Лендинг (порядок - черновик)

| Блок | Тип | Данные | На старом сайте |
|---|---|---|---|
| Первый экран | `hero` | ручное | слоган и кнопка «О нас» |
| О центре | `text` | ручное | 3 абзаца и логотип со слонами |
| Новости | `news` | VK | не было («Блог» - статьи, см. вопрос 2) |
| Услуги | `cards` | ручное: диагностика, ABA-терапия, альтернативная коммуникация, логопедия | блок на главной |
| Направления | `text` или `cards` | ручное: 9 направлений | список на «О нас» |
| Цифры | `facts` | ручное (вопрос 4) | «Цифры» на главной, цифры центра на «О нас» |
| Специалисты | `cards` | ручное: 16 человек | «Сотрудники», страница на каждого |
| О нас | `text` | ручное: цитата, миссия, руководство | страница «О нас» |
| Отзывы | `cards` | ручное: 3 отзыва (вопрос 5) | на «О нас» |
| Контакты | `contacts` | ручное | страница «Контакты» |

Отдельные страницы: `/news/` (архив), `/news/<slug>/`, `/specialisty/<имя>/`, 404. Шапка:
логотип, меню, телефон. Подвал: руководство одной строкой, адрес, телефоны, VK, год.

Старые адреса (P2-5): `/о-нас/` -> `/#about`, `/контакты/` -> `/#contacts`, `/сотрудники/`
-> `/#specialists`, `/<фамилия-и-о>/` -> `/specialisty/<имя>/`, записи блога - по вопросу 2.

**Не переносим:** комментарии (632 спама), поиск, «Пример страницы», черновики
WordPress, Галерею (В4). Политика конфиденциальности - новая, к публичному запуску (О7).

## Вопросы к Павлу

1. ~~Адреса латиницей или кириллицей~~ - снято: разделы стали блоками лендинга; у
   отдельных страниц (`/news/`, `/specialisty/`) - латиница.
2. **Статьи.** На старом сайте в «Блоге» 4 статьи специалистов (СДВГ и аутизм, агрессия,
   тревожные симптомы, лагерь 2024). Блок-ряд «Статьи» со своими адресами у статей или не
   переносить?
3. ~~Одна страница услуг или по странице на каждую~~ - снято: ряд карточек с раскрытием.
4. **Цифры** («В Крыму 1500 детей с аутизмом - Минздрав России 2024» и т.п.) без ссылок
   на источники: найти источники, заменить на цифры центра или убрать?
5. **Отзывы**: в первом названо имя ребенка - предлагаю убрать.
6. **Карта**: вместо встроенной карты Google - ссылка «Открыть в Яндекс Картах».
7. **Филиалы**: «2 филиала», а адрес один - нужен второй?
8. **Иллюстрации к услугам** похожи на картинки из Canva: можно ли их использовать?
