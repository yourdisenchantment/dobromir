# Центр в цифрах (`facts`)

**Где на сайте:** главная, полоса с крупными цифрами и значками над ними. На телефоне по
две в ряд, на большом экране - по четыре. **Файл:** `site/content/blocks/facts/block.json`.

Общие правила - в [HOWTO-add-content.md](../HOWTO-add-content.md).

## Поля

| Поле | Обязательно | Что это | Ограничения |
|---|---|---|---|
| `type` | да | всегда `"facts"` | не менять |
| `menu` | нет | пункт меню в шапке | до 20 знаков |
| `title` | да | заголовок раздела | |
| `items` | да | цифры | хотя бы одна; лучше четыре или две - ровные ряды |
| `items[].icon` | нет | значок над цифрой | имя из списка ниже |
| `items[].value` | да | сама цифра | коротко: «250+», «0–18», «15 лет» |
| `items[].label` | да | подпись под цифрой | «детей занимаются в центре» |
| `items[].source` | нет | откуда цифра, если она чужая: `{ "title": "...", "url": "https://..." }` | `url` можно не писать |

**Значки** (`icon`) - имя без `.svg`: `accessibility_new`, `calendar_month`,
`child_care`, `diversity_3`, `family_restroom`, `favorite`, `fingerprint`, `groups`,
`health_and_safety`, `location_on`, `meeting_room`, `neurology`, `psychology`,
`record_voice_over`, `school`, `sentiment_satisfied`, `stethoscope`,
`volunteer_activism`. Как выглядят - открыть `site/src/assets/icons/<имя>.svg` или найти
имя на fonts.google.com/icons. Нужного нет - это правка
кода: новый файл в `site/src/assets/icons/` (как - в `docs/HOWTO-change.md`).

## Изменить

- **Цифру** - `value`; подпись - `label`; значок - `icon`.
- Диапазон пишите через короткое тире без пробелов: `"0–18"`.

## Добавить

Новую цифру - в `items` в нужное место, через запятую:

```json
{ "icon": "school", "value": "15", "label": "лет работы" }
```

Чужая цифра - с источником:

```json
{
    "icon": "diversity_3",
    "value": "1500",
    "label": "детей с аутизмом в Крыму",
    "source": { "title": "Минздрав РК, 2024", "url": "https://..." }
}
```

## Убрать

- Цифру - удалить ее `{ ... }` из `items` вместе с запятой.
- Значок у цифры - удалить строку `"icon": ...`.
- Раздел - [menu-and-order.md](menu-and-order.md).

## Переставить

Порядок на сайте - порядок в `items`.

## Частые ошибки

- `items.1.icon: нет такой иконки; есть ...` - опечатка в имени значка, сборка перечислит
  все имеющиеся.
- `items.0.value: value (число): пусто` - нет цифры. Цифра пишется в кавычках, как текст:
  `"250+"`, а не `250+`.

## Для нейросети

> Правь только `site/content/blocks/facts/block.json` по `docs/content/facts.md`. Значок -
> только из списка в документе; `value` - строка в кавычках. Количество цифр лучше четное.
> Чужие цифры - с `source`. После правки запусти `npm run build` в `site/` и исправь
> ошибки по их тексту.
