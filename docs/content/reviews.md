# Отзывы (`reviews`)

**Где на сайте:** главная, раздел «Что говорят родители» - карусель карточек-цитат.
**Файл:** `site/content/blocks/reviews/block.json`.

Общие правила - в [HOWTO-add-content.md](../HOWTO-add-content.md).

## Поля

| Поле | Обязательно | Что это | Ограничения |
|---|---|---|---|
| `type` | да | всегда `"quotes"` | не менять |
| `menu` | нет | пункт меню в шапке | до 20 знаков |
| `title` | да | заголовок раздела | |
| `items` | да | отзывы | хотя бы один |
| `items[].text` | да | текст отзыва | одной строкой, без переносов |
| `items[].author` | нет | кто написал | без автора - подпись «Отзыв родителей» |

**Личные данные.** Это отзывы о детях с особенностями развития. Имен, фамилий и
диагнозов детей в тексте не оставлять; автор - «Мама воспитанницы», «Папа Миши» тоже
лишнее, лучше «Мама воспитанника» или вовсе без автора. Отзыв из VK или переписки
публикуется с согласия написавшего.

## Изменить

Найти отзыв в `items` и поправить `text` или `author`. Править смысл чужого отзыва
нельзя; опечатки и лишние пробелы - можно (пробелы и кавычки сборка поправит сама).

## Добавить

В `items`, через запятую; первым в списке - первый в карусели:

```json
{
    "text": "Текст отзыва.",
    "author": "Мама воспитанника"
}
```

## Убрать

- Отзыв - удалить его `{ ... }` из `items` вместе с запятой.
- Автора - удалить строку `"author": ...`, подпись станет «Отзыв родителей».
- Раздел - [menu-and-order.md](menu-and-order.md).

## Переставить

Порядок в карусели - порядок в `items`.

## Частые ошибки

- `JSON не читается` - в тексте отзыва прямые кавычки `"`, они закрывают строку раньше
  времени. Пишите «елочки» или `\"` - сборка заменит `\"...\"` на «...».
- `items: нужен хотя бы один отзыв` - список пуст; убрать раздел - через `page.json`.

## Для нейросети

> Правь только `site/content/blocks/reviews/block.json` по `docs/content/reviews.md`. Не
> меняй смысл отзывов, не добавляй имен, фамилий и диагнозов детей; если они есть в
> исходном тексте - убери их и скажи об этом. Автор - обезличенно или без поля
> `author`. После правки запусти `npm run build` в `site/` и исправь ошибки по их тексту.
