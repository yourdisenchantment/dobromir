# Порядок разделов и меню (`page.json`)

**Где на сайте:** в каком порядке разделы идут на главной сверху вниз и какие пункты
есть в меню шапки. **Файлы:** `site/content/page.json` (порядок) и поле `menu` в
`block.json` каждого раздела (пункт меню).

Общие правила - в [HOWTO-add-content.md](../HOWTO-add-content.md).

## Порядок разделов

`page.json` - список имен папок из `site/content/blocks/` сверху вниз:

```json
{
    "blocks": [
        "hero",
        "center",
        "facts",
        "news",
        "services",
        "directions",
        "specialists",
        "about",
        "reviews",
        "contacts"
    ]
}
```

| Хочу | Как |
|---|---|
| Переставить раздел | передвинуть его имя в списке |
| Убрать раздел с главной | удалить имя из списка; папку можно не трогать - вернуть раздел значит вписать имя обратно |
| Вернуть раздел | вписать имя папки в нужное место |

Нельзя убрать `contacts`: из него шапка и подвал берут телефон. Не стоит убирать
`hero`: в нем главный заголовок страницы. Одно имя дважды - ошибка.

## Меню в шапке

Пункт меню есть у раздела, в `block.json` которого есть поле `menu`:

```json
"menu": "Услуги",
```

- Надпись - до 20 знаков.
- Пункты идут в том же порядке, что разделы в `page.json`.
- Нет поля - нет пункта. Пока посетитель листает такой раздел, в меню подсвечен
  ближайший пункт выше.
- Сейчас пунктов семь, восемь - предел: меню помещается в одну строку на экране от
  1280 px, на узких экранах прячется под кнопку «Меню». Девятый пункт или длинные
  надписи - сначала к разработчику (порог задан в `site/src/components/SiteHeader.astro`).

| Хочу | Как |
|---|---|
| Добавить пункт | в `block.json` раздела строка `"menu": "Надпись",` после `"type": ...` |
| Переименовать | поменять текст `menu` |
| Убрать пункт, оставив раздел | удалить строку `"menu": ...` |

## Новый раздел

1. Скопировать папку похожего раздела под новым именем, например `blocks/prices/` из
   `blocks/services/`. Имя - латиницей, маленькими буквами, можно цифры и дефис: оно же
   адрес раздела (`/#prices`).
2. Поправить `block.json` по документу того вида, который скопировали: `cards` -
   [services.md](services.md), `text` - [center.md](center.md), `quotes` -
   [reviews.md](reviews.md), `facts` - [facts.md](facts.md).
3. Вписать имя папки в `page.json`.

Раздел нового вида (таблица цен, видео, галерея) - это новый тип, его добавляет
разработчик (`docs/HOWTO-change.md`). Второй блок специалистов или контактов сделать
нельзя.

## Частые ошибки

- `blocks: нет файла site/content/blocks/prices/block.json` - опечатка в имени или нет
  папки.
- `blocks: блок services указан дважды`.
- `menu: не длиннее 20 знаков`.

## Для нейросети

> Порядок разделов меняй только в `site/content/page.json`, пункты меню - полем `menu` в
> `block.json` раздела, по `docs/content/menu-and-order.md`. Не убирай `contacts`. Не
> больше восьми пунктов меню, до 20 знаков каждый. Новый раздел - копия папки
> существующего того же вида. После правки запусти `npm run build` в `site/`.
