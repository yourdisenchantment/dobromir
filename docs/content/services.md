# Услуги (`services`)

**Где на сайте:** главная, раздел «Услуги» - карточки «черепицей» (как архив новостей).
**Файл:** `site/content/blocks/services/block.json`.

Блок того же вида (`cards`), что и «Направления» ([directions.md](directions.md)): поля
одинаковые, разница в том, как их принято заполнять - в услугах у карточки текст, в
направлениях - список. Общие правила - в [HOWTO-add-content.md](../HOWTO-add-content.md).

## Поля

| Поле | Обязательно | Что это | Ограничения |
|---|---|---|---|
| `type` | да | всегда `"cards"` | не менять |
| `menu` | нет | пункт меню в шапке | до 20 знаков, см. [menu-and-order.md](menu-and-order.md) |
| `title` | да | заголовок раздела | |
| `intro` | нет | абзац под заголовком | |
| `items` | да | карточки | хотя бы одна |
| `items[].title` | да | заголовок карточки | коротко: «Логопедия» |
| `items[].subtitle` | нет | строка под заголовком | например, «от 18 месяцев» |
| `items[].text` | нет | описание | два-три предложения |
| `items[].list` | нет | пункты списком | `["пункт", "пункт"]` |

Можно и `text`, и `list` в одной карточке: сначала текст, под ним список.

## Изменить

Найти карточку по `title` в `items` и поменять нужное поле.

## Добавить

Новую карточку - в `items` в то место, где она должна стоять, через запятую:

```json
{
    "title": "Сенсорная интеграция",
    "text": "Короткое описание в два-три предложения."
}
```

С подзаголовком и списком:

```json
{
    "title": "Подготовка к школе",
    "subtitle": "от 5 лет",
    "text": "Занятия в маленьких группах.",
    "list": ["Чтение и письмо", "Счет", "Внимание и усидчивость"]
}
```

## Убрать

- Карточку - удалить ее `{ ... }` из `items` вместе с запятой.
- Поле карточки (`subtitle`, `text`, `list`) - удалить строку.
- Раздел с главной - [menu-and-order.md](menu-and-order.md).

## Переставить

Карточки идут на сайте в порядке `items`: переставить записи в списке. Черепица
раскладывает их по колонкам сама, сверху вниз.

## Частые ошибки

- `items: нужна хотя бы одна карточка` - список пуст; убрать раздел - через `page.json`.
- `лишнее поле description` - у карточки нет такого поля, есть `text`.

## Для нейросети

> Правь только `site/content/blocks/services/block.json` по `docs/content/services.md`. Не
> меняй `type`, у карточки только поля `title`, `subtitle`, `text`, `list`. Порядок
> карточек - порядок в `items`. Тексты на русском, кавычки «елочки», тире «—». После
> правки запусти `npm run build` в `site/` и исправь ошибки по их тексту.
