# Контакты (`contacts`)

**Где на сайте:** главная, раздел «Контакты» - адрес, как добраться, ссылка на карту,
телефоны, группа VK. **Отсюда же** телефон берут шапка сайта (кнопка звонка), подвал
всех страниц и страницы специалистов. **Файл:** `site/content/blocks/contacts/block.json`.

Блок обязателен: без него сборка остановится («нужен блок типа contacts»). Общие
правила - в [HOWTO-add-content.md](../HOWTO-add-content.md).

## Поля

| Поле | Обязательно | Что это | Ограничения |
|---|---|---|---|
| `type` | да | всегда `"contacts"` | не менять |
| `menu` | нет | пункт меню в шапке | до 20 знаков |
| `title` | да | заголовок раздела | |
| `address` | да | адрес одной строкой | «Симферополь, ул. Желябова, 44» |
| `text` | нет | как добраться, где оставить машину | один абзац |
| `map` | нет | ссылка на карту | полный адрес `https://...` |
| `phones` | да | телефоны | хотя бы один; **первый - для записи** |
| `phones[].label` | да | подпись | «Запись — только по телефону» |
| `phones[].number` | да | номер | в любом привычном виде: `+7 978 229-48-54` |
| `vk` | нет | группа VK | полный адрес `https://vk.com/...` |

Ссылку для звонка сайт делает из номера сам (`+7 978 229-48-54` -> `tel:+79782294854`).

## Изменить

- **Телефон записи** - `number` у первой записи в `phones`. Он сменится в шапке, подвале,
  контактах и на страницах специалистов. **Кнопка «Записаться» на первом экране его не
  берет** - поменять `href` и там ([hero.md](hero.md)).
- **Адрес** - `address`; карта - `map`. Ссылка на Яндекс.Карты по адресу:
  `https://yandex.ru/maps/?text=Симферополь, улица Желябова, 44`.
- **Как добраться** - `text`.

## Добавить

Телефон - в `phones`, через запятую. Первым ставьте только новый телефон записи:

```json
"phones": [
    { "label": "Запись — только по телефону", "number": "+7 978 229-48-54" },
    { "label": "Общий телефон", "number": "+7 978 799-17-09" },
    { "label": "Бухгалтерия", "number": "+7 978 000-00-00" }
]
```

## Убрать

- Телефон - удалить его `{ ... }` из `phones`. Последний телефон удалить нельзя.
- Карту, текст, ссылку на VK - удалить строку поля.
- Раздел с главной убрать нельзя.

## Переставить

Порядок телефонов - порядок в `phones`; первый всегда считается телефоном для записи.

## Частые ошибки

- `map: нужна ссылка на карту` - адрес карты без `https://`.
- `phones: нужен хотя бы один телефон` - список пуст.

## Для нейросети

> Правь только `site/content/blocks/contacts/block.json` по `docs/content/contacts.md`.
> Первый телефон в `phones` - для записи. Если меняешь его, поменяй и `href` первой кнопки
> в `site/content/blocks/hero/block.json` (`tel:` и цифры без пробелов). Ссылки - полные,
> с `https://`. Блок не убирай. После правки запусти `npm run build` в `site/` и исправь
> ошибки по их тексту.
