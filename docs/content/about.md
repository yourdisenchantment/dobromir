# «О нас» (`about`)

**Где на сайте:** главная, после специалистов - цитата, миссия и принципы центра.
**Файл:** `site/content/blocks/about/block.json`.

Блок того же вида (`text`), что и «О центре»: все поля и рецепты - в
[center.md](center.md), здесь только отличия. Общие правила - в
[HOWTO-add-content.md](../HOWTO-add-content.md).

## Что здесь есть

- `menu: "О нас"` - пункт меню в шапке.
- `quote` - цитата над текстом (сейчас Томаса Фуллера). Поменять - поля `text` и
  `author`; убрать - удалить `quote` целиком.
- `paragraphs` - абзацы; первый крупнее, строки с «— » - пункты списка.

## Рецепты

| Хочу | Как |
|---|---|
| Поправить абзац | поменять текст строки в `paragraphs` |
| Добавить абзац или список | новая строка в `paragraphs`, пункты - с «— » в начале |
| Сменить цитату | `quote.text` и `quote.author` |
| Цитата без автора | удалить `"author": ...` внутри `quote` |
| Убрать цитату | удалить поле `quote` |
| Переименовать пункт меню | `menu`, до 20 знаков |
| Убрать раздел с главной | [menu-and-order.md](menu-and-order.md) |

Примеры JSON и частые ошибки - в [center.md](center.md).

## Для нейросети

> Правь только `site/content/blocks/about/block.json` по `docs/content/about.md` и
> `docs/content/center.md` (тот же тип `text`). Не меняй `type`, не добавляй полей вне
> таблицы. Абзацы - строки в `paragraphs`, пункты списка начинаются с «— ». После правки
> запусти `npm run build` в `site/` и исправь ошибки по их тексту.
