# Первый экран (`hero`)

**Где на сайте:** самый верх главной - крупный заголовок, подзаголовок и одна-две кнопки.
**Файл:** `site/content/blocks/hero/block.json`.

Общие правила (как проверить, как опубликовать, что сборка правит сама) - в
[HOWTO-add-content.md](../HOWTO-add-content.md).

## Поля

| Поле | Обязательно | Что это | Ограничения |
|---|---|---|---|
| `type` | да | всегда `"hero"` | не менять |
| `menu` | нет | пункт меню в шапке | до 20 знаков, см. [menu-and-order.md](menu-and-order.md) |
| `title` | да | главный заголовок страницы | одна фраза; это заголовок для поисковиков тоже |
| `lead` | нет | подзаголовок | одна-две фразы |
| `actions` | нет | кнопки | не больше двух; первая - основная (яркая) |
| `actions[].label` | да | надпись на кнопке | коротко: «Записаться по телефону» |
| `actions[].href` | да | куда ведет | `tel:+7978...` - звонок, `#services` - раздел главной, `https://...` - сайт |

## Изменить

- **Текст заголовка или подзаголовка** - поменять текст в кавычках у `title` или `lead`.
- **Надпись на кнопке** - `label`.
- **Куда ведет кнопка** - `href`. Раздел главной пишется как `#` и имя папки раздела:
  `#services`, `#specialists`, `#contacts`.
- **Телефон в кнопке записи** - `href` вида `tel:+79782294854`: только `+` и цифры, без
  пробелов. **Сменили телефон записи в контактах - поменяйте и здесь**: кнопка его сама не
  берет.

## Добавить

Вторую кнопку - в список `actions`, через запятую после первой:

```json
"actions": [
    { "label": "Записаться по телефону", "href": "tel:+79782294854" },
    { "label": "Услуги центра", "href": "#services" }
]
```

Третью нельзя: сборка остановится с ошибкой «actions: не больше двух кнопок».

## Убрать

- Кнопку - удалить ее `{ ... }` из `actions` вместе с запятой перед ней.
- Все кнопки - `"actions": []` или удалить поле целиком.
- Подзаголовок - удалить строку `"lead": ...` (и запятую в конце предыдущей строки, если
  `lead` был последним).

Убрать первый экран с главной совсем - в [menu-and-order.md](menu-and-order.md), но
делать так не стоит: без него у страницы нет главного заголовка.

## Переставить

Кнопки - поменять местами записи в `actions`: первая всегда основная.

## Частые ошибки

- `actions.0.href: href (ссылка): пусто` - у кнопки нет ссылки.
- Кнопка «Записаться» звонит на старый номер - поменяли телефон только в контактах.

## Для нейросети

> Правь только `site/content/blocks/hero/block.json` по `docs/content/hero.md`. Не меняй
> `type`, не добавляй полей, которых нет в таблице. Кнопок не больше двух. Телефон в
> `href` - `tel:` и цифры без пробелов, тот же, что первый в
> `site/content/blocks/contacts/block.json`. После правки запусти `npm run build` в
> `site/` и исправь ошибки по их тексту.
