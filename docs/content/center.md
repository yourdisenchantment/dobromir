# «О центре» (`center`)

**Где на сайте:** главная, сразу под первым экраном - заголовок «О центре» и несколько
абзацев. **Файл:** `site/content/blocks/center/block.json`.

Блок того же вида (`text`), что и «О нас» ([about.md](about.md)): поля и рецепты у них
одинаковые. Общие правила - в [HOWTO-add-content.md](../HOWTO-add-content.md).

## Поля

| Поле | Обязательно | Что это | Ограничения |
|---|---|---|---|
| `type` | да | всегда `"text"` | не менять |
| `menu` | нет | пункт меню в шапке | до 20 знаков, см. [menu-and-order.md](menu-and-order.md) |
| `title` | да | заголовок раздела | |
| `quote` | нет | цитата над текстом: `{ "text": "...", "author": "..." }` | `author` можно не писать |
| `paragraphs` | да | список абзацев | первый абзац на сайте крупнее остальных |

Строка абзаца, которая начинается с «— » (тире и пробел), - пункт списка. Несколько
таких строк подряд складываются в один список:

```json
"paragraphs": [
    "В центре работают:",
    "— психологи;",
    "— логопеды;",
    "— инструкторы ЛФК."
]
```

## Изменить

- **Заголовок** - `title`.
- **Абзац** - найти его в `paragraphs` и поменять текст в кавычках. Абзац - одна строка в
  кавычках, переносы внутри не нужны: сайт сам разобьет текст по ширине экрана.

## Добавить

- **Абзац** - новая строка в `paragraphs` в нужном месте, через запятую:

  ```json
  "paragraphs": [
      "Первый абзац.",
      "Новый абзац.",
      "Последний абзац."
  ]
  ```

- **Список** - строки с «— » в начале, как выше.
- **Цитату** - поле `quote` после `title`:

  ```json
  "quote": { "text": "Текст цитаты.", "author": "Автор" },
  ```

## Убрать

- Абзац - удалить строку из `paragraphs` вместе с запятой (у последней строки запятой
  после нет, поэтому если удаляете последнюю - уберите запятую у новой последней).
- Цитату - удалить поле `quote` целиком.
- Раздел с главной - в [menu-and-order.md](menu-and-order.md).

## Переставить

Абзацы - поменять строки местами в `paragraphs`. Раздел на главной - в
[menu-and-order.md](menu-and-order.md).

## Частые ошибки

- `paragraphs: нужен список абзацев` - вместо списка `[ ... ]` написана одна строка.
- `JSON не читается` - чаще всего лишняя или пропущенная запятая между абзацами.

## Для нейросети

> Правь только `site/content/blocks/center/block.json` по `docs/content/center.md`. Не
> меняй `type`, не добавляй полей вне таблицы. Каждый абзац - одна строка в списке
> `paragraphs`; пункты списка начинаются с «— ». Тексты на русском, кавычки «елочки»,
> тире «—». После правки запусти `npm run build` в `site/` и исправь ошибки по их тексту.
