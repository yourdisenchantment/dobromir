# Направления (`directions`)

**Где на сайте:** главная, раздел «Направления» - карточки «черепицей», в каждой список
занятий. **Файл:** `site/content/blocks/directions/block.json`.

Блок того же вида (`cards`), что и «Услуги»: таблица полей - в
[services.md](services.md). Здесь принято так: у карточки `title` (группа направлений) и
`list` (что в нее входит); `text` и `subtitle` можно, но обычно не нужны. Общие правила -
в [HOWTO-add-content.md](../HOWTO-add-content.md).

## Изменить

- **Название группы** - `title` карточки.
- **Пункт списка** - поменять строку в `list`. Возраст и уточнения - в скобках в той же
  строке: «Раннее развитие (от 18 месяцев)».

## Добавить

- **Пункт в группу** - новая строка в `list` нужной карточки, через запятую:

  ```json
  "list": [
      "Консультации родителей",
      "Семейное консультирование",
      "Новый пункт"
  ]
  ```

- **Новую группу** - карточка в `items`:

  ```json
  {
      "title": "Движение",
      "list": ["Адаптивная физкультура", "Массаж", "ЛФК"]
  }
  ```

## Убрать

- Пункт - удалить строку из `list` (и запятую, если она стала лишней).
- Группу - удалить карточку `{ ... }` из `items`.
- Раздел с главной - [menu-and-order.md](menu-and-order.md).

## Переставить

- Группы - порядок карточек в `items`.
- Пункты внутри группы - порядок строк в `list`.

## Частые ошибки

- `items.2.list.4: list (пункт): пусто` - в списке пустая строка `""`.
- `JSON не читается` - пропущена запятая между пунктами или после `]`.

## Для нейросети

> Правь только `site/content/blocks/directions/block.json` по
> `docs/content/directions.md` и таблице полей из `docs/content/services.md`. Не меняй
> `type`. У карточки - `title` и `list`; возраст и уточнения пиши в скобках в строке
> пункта. Порядок - порядок в списках. После правки запусти `npm run build` в `site/` и
> исправь ошибки по их тексту.
